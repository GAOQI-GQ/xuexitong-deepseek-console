# 学习通 DeepSeek 助手（控制台版）

> 关键词：学习通、超星、学习通刷课、自动刷课、自动答题、视频弹题、章节测验、DeepSeek、书签脚本、免油猴

一个运行在本机的学习通课程辅助脚本：自动播放视频、回答章节测验、处理视频中途弹题、自动切换下一节，并在遇到“暂无内容”的空小节时自动跳过。

本项目基于 GitHub 开源项目 **xuexitongScript** 二次修改（二改），原项目版权归原作者所有。

## 功能

- 自动播放课程视频，视频结束后进入下一学习步骤
- 同一个学习页面里有两段或更多视频时（例如上下叠放的多个播放器），会按页面顺序逐段播放，全部播完才点击“下一节”，不会漏掉后面视频的任务点；播放器若在同一个 video 元素里换入下一段，也能识别为新的视频继续播放
- 一段视频结束后若下一段还没渲染出来，会再确认两次再决定进入下一节，避免因为加载慢而跳过视频
- 自动识别章节测验中的单选题、多选题、判断题，调用 DeepSeek API 作答并提交
- 识别视频播放中途弹出的题目，自动作答；答错后自动换一个没试过的答案重新作答，答对后自动点击“继续学习”恢复播放
- 一套多题（如“共 2 题，已答对 1 题”）答对后同样会自动点击“继续学习”；结果面板还在时即使视频刚好播完也不会误点“下一节”，等弹题处理完再切换
- “继续学习”不再要求按钮文字与标签完全一致：按钮带图标、空格或换行时也能识别，并会扫描播放器内嵌的多层 frame；点击时同时触发鼠标与指针事件，兼容只监听 mousedown 的按钮
- 多选题重答前会先取消上一次勾选的选项，再按新答案勾选，避免新旧选项叠加；支持“真遗憾，再接再厉”等错误提示
- 答错后会把页面的错误反馈和已尝试的答案一起交给 DeepSeek 重新判断；如果 AI 仍重复旧答案，会再要求换一个组合，仍不行才用排除法兜底
- 面板显示“真遗憾”等错误提示且选项仍保持勾选时，不会被误判成“已通过”，会继续重答而不是停住
- 视频弹题答错后选项消失或无法重选时，等待 8 秒仍无法继续就自动点击“下一节”；连续多次答错也会自动跳过，避免卡住
- 不依赖具体提示文案：即使遇到没见过的错误提示，也会按“未通过”继续重答；连续失败 3 次自动跳过
- 切换章节时自动处理“当前章节还有任务点未完成，是否去完成？”弹窗，点击“去完成”后继续任务，不会卡在弹窗上
- 全页面扫描题目与选项，兼容多种页面结构
- 视频卡住时自动恢复播放，找不到视频时自动重试
- 视频进度已到结尾但播放器没有发出“播放结束”事件时（例如最后一段网络被重置），停留在结尾 6 秒后自动切换本页下一段视频或下一节，不会一直循环“尝试恢复播放”
- DeepSeek 输出被截断时自动降级重试，不会提交残缺答案
- 大章节显示“暂无内容”时自动点击“下一节”跳过，最多连续跳过 10 个
- 页面整页跳转后通过辅助窗口自动恢复脚本
- 启动时自动最小化命令行窗口，并在 Edge 中打开学习通
- 单文件运行，只通过浏览器书签注入，无需复制粘贴脚本

## 文件说明

只需要一个文件：

| 文件 | 作用 |
| --- | --- |
| `学习通自动刷课 G版.cmd` | 单文件启动器：内置本地服务、可视化设置页和浏览器脚本 |

不用建文件夹，也不用把几个文件放在一起。双击后它会自动在系统临时目录释放服务端文件，正常退出时删除。`README.md` 只是说明文档，可以不放。

## 环境要求

- Windows 10 / 11
- Microsoft Edge
- [Node.js](https://nodejs.org) LTS 版本
- DeepSeek API Key（[platform.deepseek.com](https://platform.deepseek.com) 注册后创建，API 为按量付费）

## 使用方法

1. 双击 `学习通自动刷课 G版.cmd`。命令行窗口会自动最小化，并在 Edge 中打开学习通（`https://i.chaoxing.com/`）。
2. 首次使用会弹出一个可视化的设置窗口，粘贴 DeepSeek API Key，勾选“记住密钥”后点击“保存并启动”。之后启动会自动读取已保存的 Key，不再弹设置窗口。如果没看到设置窗口，打开 `http://127.0.0.1:37841/setup`。
3. 在 Edge 中登录学习通，进入课程播放页（地址包含 `/mycourse/studentstudy`）。
4. 第一次使用时，在 Edge 里添加一个书签（只需做一次）：
   - 按 `Ctrl+Shift+O` 打开收藏夹管理，添加一个新收藏夹。
   - 名称填“学习通自动答题”。
   - 网址填下面这一整行（必须以 `javascript:` 开头）：

```javascript
javascript:(async()=>{try{const r=await fetch('http://127.0.0.1:37841/script',{cache:'no-store'});if(!r.ok)throw new Error('HTTP '+r.status);const s=document.createElement('script');s.textContent=await r.text();document.documentElement.appendChild(s);s.remove()}catch(e){alert('注入失败：'+e.message)}})()
```

5. 以后每次进入课程播放页，点一下这个书签即可注入脚本，不需要按 `F12`，也不需要复制粘贴。
6. 浏览器询问是否允许访问本地网络时选择“允许”；脚本弹出的辅助窗口不要关闭。

需要查看日志或停止服务时，从任务栏还原最小化的 `DeepSeek Local Service` 窗口，关闭它即可停止服务。

脚本启动后会自动开始播放与答题。书签每次都会向本地服务拉取**本次启动**注入好令牌的脚本，所以服务重启后不用修改书签。

## 密钥记忆

- 勾选“记住密钥”后，Key 会使用 Windows 当前用户的 DPAPI 加密，保存在 `%APPDATA%\xuexitong-deepseek\config.json`，下次启动自动加载，无需重新输入。
- 需要更换或删除时，打开 `http://127.0.0.1:37841/setup`，输入新 Key 或点击“清除已保存的密钥”。
- 不勾选“记住密钥”时，Key 只在本次运行期间保留，不写入磁盘。

## 注意事项

- 如果之前运行过旧版服务，先还原并关闭旧的 `DeepSeek Local Service` 窗口，再双击单文件版，否则 37841 端口会被占用。
- 每次重启本地服务都会更换临时令牌，但书签会自动拉取最新脚本，不需要重新复制或修改书签。
- 如果点击书签没有反应，先确认最小化的服务窗口还在运行，且课程页地址包含 `/mycourse/studentstudy`；刷新页面后再点一次。
- 本地服务只监听 `127.0.0.1`；勾选“记住密钥”时 Key 会加密保存在本机，答题内容会发送至 DeepSeek API。
- 使用 API 会产生费用；AI 可能答错；自动化操作可能触发平台风控。
- 如果页面出现“已在调试程序中暂停”，在开发者工具中按 `F8` 恢复，或在 Sources 面板关闭“遇到异常时暂停”。
